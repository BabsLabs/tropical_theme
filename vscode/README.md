# Tropical Theme

Twelve tropical color themes for VS Code, each named after a tropical place and colored from the plants and animals
that live there.

## Installing

Install the `.vsix` from the command line:

```bash
code --install-extension tropical-theme-1.0.0.vsix
```

Or, in the Extensions view, open the **…** menu and choose **Install from VSIX…**. One install adds all twelve themes.

## Choosing a theme

Open the Command Palette, run **Preferences: Color Theme** (<kbd>Cmd</kbd>+<kbd>K</kbd> <kbd>Cmd</kbd>+<kbd>T</kbd>,
or <kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>T</kbd>), and type `Tropical` to preview the themes.

To switch between a light and a dark theme with your system's appearance, add this to your settings:

```json
"window.autoDetectColorScheme": true,
"workbench.preferredLightColorTheme": "Tropical Beach",
"workbench.preferredDarkColorTheme": "Tropical Jungle"
```
